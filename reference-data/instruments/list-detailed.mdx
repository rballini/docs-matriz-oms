Igual que [Lista de instrumentos disponibles](/reference-data/instruments/list), pero con el **detalle completo** de cada instrumento: segmento, precios límite, vencimiento, moneda, tipos de orden soportados, etc.

```http
GET https://api.{urlbase}.(matrizoms|xoms).com.ar/rest/instruments/details
```

<Tip>
  La respuesta incluye todos los instrumentos disponibles y puede ser extensa. Si solo necesitás un instrumento, usá [Descripción detallada de un instrumento](/reference-data/instruments/detail). Para el resto de los casos, consultá este método una vez y reutilizá el resultado en lugar de pedirlo en cada operación.
</Tip>

## Parámetros

Este método **no recibe parámetros**. Solo requiere el header de autenticación.

<AuthHeader />

## Ejemplos de request

<CodeGroup>
```bash cURL
# BASE_URL=https://api.{urlbase}.matrizoms.com.ar  (o .xoms.com.ar según tu ambiente)
curl "$BASE_URL/rest/instruments/details" \
  -H "X-Auth-Token: $MATRIZ_TOKEN"
```

```python Python
import os
import requests

BASE_URL = f"https://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar"
TOKEN = os.environ["MATRIZ_TOKEN"]

respuesta = requests.get(
    f"{BASE_URL}/rest/instruments/details",
    headers={"X-Auth-Token": TOKEN},
    timeout=60,
)
respuesta.raise_for_status()

# Índice por símbolo para consultar el detalle sin volver a llamar a la API
por_simbolo = {
    i["instrumentId"]["symbol"]: i for i in respuesta.json()["instruments"]
}
dlr = por_simbolo.get("DLR/DIC26")
if dlr:
    print(dlr["minPriceIncrement"], dlr["lowLimitPrice"], dlr["highLimitPrice"])
```

```javascript Node.js
// Node.js 18 o superior (fetch nativo)
const BASE_URL = `https://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar`;

const respuesta = await fetch(`${BASE_URL}/rest/instruments/details`, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN },
});
const datos = await respuesta.json();

// Índice por símbolo para consultar el detalle sin volver a llamar a la API
const porSimbolo = new Map(
  datos.instruments.map((i) => [i.instrumentId.symbol, i]),
);
const dlr = porSimbolo.get("DLR/DIC26");
if (dlr) {
  console.log(dlr.minPriceIncrement, dlr.lowLimitPrice, dlr.highLimitPrice);
}
```
</CodeGroup>
