Este método permite listar todos los instrumentos que pertenecen al mismo **segmento de mercado**. Podés obtener los segmentos habilitados con [Lista de segmentos disponibles](/reference-data/segments/list).

```http
GET https://api.{urlbase}.(matrizoms|xoms).com.ar/rest/instruments/bySegment
```

## Parámetros

<Warning>
  Los nombres de los parámetros de este método llevan **mayúsculas**: `MarketSegmentID` y `MarketID`. Respetá exactamente esa escritura.
</Warning>

<AuthHeader />

<ParamField query="MarketSegmentID" type="string" required>
  Código que identifica al segmento. Valores posibles: `DDF`, `DDA`, `DUAL`, `U-DDF`, `U-DDA`, `U-DUAL`, `MERV`.
</ParamField>

<ParamField query="MarketID" type="string" required>
  ID del mercado al que pertenece el segmento. Valor permitido: `ROFX`.
</ParamField>

## Ejemplos de request

Listar los instrumentos del segmento `DDF`:

<CodeGroup>
```bash cURL
# BASE_URL=https://api.{urlbase}.matrizoms.com.ar  (o .xoms.com.ar según tu ambiente)
curl --get "$BASE_URL/rest/instruments/bySegment" \
  -H "X-Auth-Token: $MATRIZ_TOKEN" \
  --data-urlencode "MarketSegmentID=DDF" \
  --data-urlencode "MarketID=ROFX"
```

```python Python
import os
import requests

BASE_URL = f"https://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar"
TOKEN = os.environ["MATRIZ_TOKEN"]

respuesta = requests.get(
    f"{BASE_URL}/rest/instruments/bySegment",
    headers={"X-Auth-Token": TOKEN},
    params={"MarketSegmentID": "DDF", "MarketID": "ROFX"},
    timeout=30,
)
respuesta.raise_for_status()

for instrumento in respuesta.json()["instruments"]:
    print(instrumento["symbol"])
```

```javascript Node.js
// Node.js 18 o superior (fetch nativo)
const BASE_URL = `https://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar`;

const params = new URLSearchParams({ MarketSegmentID: "DDF", MarketID: "ROFX" });

const respuesta = await fetch(`${BASE_URL}/rest/instruments/bySegment?${params}`, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN },
});
const datos = await respuesta.json();

for (const { symbol } of datos.instruments) {
  console.log(symbol);
}
```
</CodeGroup>
