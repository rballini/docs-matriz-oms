Los **instrumentos** (securities) son los distintos activos disponibles para negociar en **A3 Mercados** y **BYMA**. Se agrupan por tipo, identificado con el estándar **CFI Code**, y cada uno tiene características propias que podés consultar pidiendo su detalle.

Este método devuelve una lista con todos los instrumentos disponibles para negociarse en A3 Mercados. Por cada instrumento devuelve el **símbolo**, el **ID del mercado** al que pertenece y el **código CFI**.

```http
GET https://api.{urlbase}.(matrizoms|xoms).com.ar/rest/instruments/all
```

<Tip>
  Si necesitás las características operativas de cada instrumento (precios límite, vencimiento, moneda, tipos de orden), usá [Lista detallada de instrumentos](/reference-data/instruments/list-detailed). Si solo necesitás un instrumento, usá [Descripción detallada de un instrumento](/reference-data/instruments/detail).
</Tip>

## Parámetros

Este método **no recibe parámetros**. Solo requiere el header de autenticación.

## Ejemplos de request

<CodeGroup>
```bash cURL
# BASE_URL=https://api.{urlbase}.matrizoms.com.ar  (o .xoms.com.ar según tu ambiente)
curl "$BASE_URL/rest/instruments/all" \
  -H "X-Auth-Token: $MATRIZ_TOKEN"
```

```python Python
import os
import requests

BASE_URL = f"https://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar"
TOKEN = os.environ["MATRIZ_TOKEN"]

respuesta = requests.get(
    f"{BASE_URL}/rest/instruments/all",
    headers={"X-Auth-Token": TOKEN},
    timeout=30,
)
respuesta.raise_for_status()

for instrumento in respuesta.json()["instruments"]:
    print(instrumento["instrumentId"]["symbol"], instrumento["cficode"])
```

```javascript Node.js
// Node.js 18 o superior (fetch nativo)
const BASE_URL = `https://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar`;

const respuesta = await fetch(`${BASE_URL}/rest/instruments/all`, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN },
});
const datos = await respuesta.json();

for (const { instrumentId, cficode } of datos.instruments) {
  console.log(instrumentId.symbol, cficode);
}
```
</CodeGroup>
