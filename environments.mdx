Cada cliente de Matriz OMS API opera sobre uno o más **ambientes propios**. No existe una URL única para todos los integradores: la URL base se arma a partir de tu identificador de cliente o ambiente y del dominio con el que fue provisto tu acceso.

## Elegí tu ambiente

<CardGroup cols={2}>
  <Card title="Testing · Demo general" icon="flask-vial">
    <span className="mx-chip">Integración y pruebas</span> <span className="mx-chip">Demo</span>

    Además de los ambientes propios de cada ALyC, existe un **ambiente demo general**. Usalo para desarrollar y probar tu integración antes de operar en producción.

    ```text API REST
    https://api.demo.matrizoms.com.ar
    ```

    ```text API WebSocket
    wss://api.demo.matrizoms.com.ar/
    ```
  </Card>

  <Card title="Producción" icon="building-columns">
    <span className="mx-chip">Operatoria real</span> <span className="mx-chip">Tu instancia</span>

    Es la instancia de tu ALyC. Reemplazá `{urlbase}` por tu identificador y usá el dominio que te fue asignado (`matrizoms` o `xoms`).

    ```text API REST
    https://api.{urlbase}.(matrizoms|xoms).com.ar
    ```

    ```text API WebSocket
    wss://api.{urlbase}.(matrizoms|xoms).com.ar/
    ```
  </Card>
</CardGroup>

<Warning>
  Las órdenes que envíes en producción son **reales**. Hacé tus primeras pruebas en el demo general.
</Warning>

<Note>
  Si no conocés tu `{urlbase}` o el dominio que te corresponde, solicitalo mediante un ticket en JIRA antes de comenzar la integración.
</Note>

## Anatomía de la URL base

La URL base se compone del esquema, el servicio, tu identificador (`{urlbase}`) y el dominio. Lo único que cambia entre las dos interfaces es el esquema.

<Tabs>
  <Tab title="API REST" icon="arrow-right-arrow-left">
    ```text
    https://api.{urlbase}.{dominio}.com.ar
    ```

    | Componente | Descripción | Ejemplo |
    | --- | --- | --- |
    | `https://` | Esquema de la API REST. | `https://` |
    | `api` | Subdominio del servicio. `api` para Trading; `api-risk` para Riesgo (solo administradores de ALyC). | `api` |
    | `{urlbase}` | Identificador del cliente o del ambiente. | `demo` |
    | `{dominio}` | `matrizoms` o `xoms`, según cómo esté provisto el ambiente. | `matrizoms` |

    Por ejemplo, para el ambiente `demo` provisto bajo el dominio `matrizoms`, la URL base de Trading es:

    ```text
    https://api.demo.matrizoms.com.ar
    ```

    Y el mismo ambiente provisto bajo el dominio `xoms`:

    ```text
    https://api.demo.xoms.com.ar
    ```
  </Tab>
  <Tab title="API WebSocket" icon="bolt">
    ```text
    wss://api.{urlbase}.{dominio}.com.ar/
    ```

    | Componente | Descripción | Ejemplo |
    | --- | --- | --- |
    | `wss://` | Esquema de la API WebSocket. | `wss://` |
    | `api.{urlbase}.{dominio}.com.ar` | **El mismo host** que la API REST de Trading. | `api.demo.matrizoms.com.ar` |
    | `/` | Ruta final de la conexión. | `/` |

    Por ejemplo, para el ambiente `demo` provisto bajo el dominio `matrizoms`:

    ```text
    wss://api.demo.matrizoms.com.ar/
    ```

    El token se obtiene por REST contra ese mismo host. Ver [API WebSocket](/websockets/overview) para los métodos de autenticación de la conexión.
  </Tab>
</Tabs>

## Del demo a producción

<Steps>
  <Step title="Integrá y probá en el demo general" icon="flask-vial">
    Conectate al demo general y recorré el flujo completo de la [Guía rápida](/quickstart): token, segmentos, una orden y la verificación de su estado.
  </Step>
  <Step title="Validá el ciclo completo de una orden" icon="arrows-spin">
    Verificá siempre el estado real de cada orden y reconciliá el estado después de una desconexión. Ver [Ciclo de vida de una orden](/guides/order-lifecycle).
  </Step>
  <Step title="Resolvé errores y reconexión" icon="triangle-exclamation">
    Manejá los errores de la API y prepará la reconexión del WebSocket. Ver [Errores](/reference/errors) y [API WebSocket](/websockets/overview).
  </Step>
  <Step title="Pedí tu instancia y tus credenciales" icon="ticket">
    Si no conocés tu `{urlbase}` o el dominio que te corresponde, solicitalo mediante un ticket en JIRA. Ver [Soporte](/support).
  </Step>
  <Step title="Cambiá la configuración, no el código" icon="sliders">
    Apuntá la aplicación a tu instancia de producción modificando las variables de entorno (`MATRIZ_URLBASE`, `MATRIZ_DOMINIO` y las credenciales). Mantené separadas las credenciales de pruebas y de producción.
  </Step>
  <Step title="Empezá con cuidado" icon="circle-check">
    Las órdenes en producción son reales: enviá primero una orden de cantidad mínima y verificá su estado antes de escalar el volumen.
  </Step>
</Steps>

## Reglas al trabajar con ambientes

<AccordionGroup>
  <Accordion title="El token se obtiene contra la URL base en la que vas a operar" icon="key">
    El token se solicita con `POST /auth/getToken` contra la URL base del ambiente y dominio que vas a usar. Utilizá cada token únicamente contra la URL base con la que lo obtuviste.
  </Accordion>
  <Accordion title="Cada dominio requiere su propio token" icon="shield-halved">
    El token obtenido en `api` no sirve para `api-risk`, y viceversa. Si tu perfil tiene acceso a ambos dominios, gestioná dos tokens por separado.
  </Accordion>
  <Accordion title="matrizoms y xoms no son intercambiables" icon="triangle-exclamation">
    Usá siempre el dominio que te fue asignado. Cambiar `matrizoms` por `xoms` (o al revés) no apunta al mismo ambiente.
  </Accordion>
</AccordionGroup>

## Buenas prácticas

Parametrizá el identificador de ambiente y el dominio en la configuración de tu aplicación, en lugar de escribir la URL completa en el código. Así podés pasar de un ambiente de pruebas a producción sin modificar el código.

<CodeGroup>
```bash .env
MATRIZ_URLBASE=demo
MATRIZ_DOMINIO=matrizoms
MATRIZ_USERNAME=tu_usuario
MATRIZ_PASSWORD=tu_contraseña
```

```python Python
import os

URLBASE = os.environ["MATRIZ_URLBASE"]                    # ej.: "demo"
DOMINIO = os.environ.get("MATRIZ_DOMINIO", "matrizoms")   # "matrizoms" o "xoms"

TRADING_BASE_URL = f"https://api.{URLBASE}.{DOMINIO}.com.ar"
```

```javascript Node.js
const URLBASE = process.env.MATRIZ_URLBASE;                 // ej.: "demo"
const DOMINIO = process.env.MATRIZ_DOMINIO ?? "matrizoms";  // "matrizoms" o "xoms"

const TRADING_BASE_URL = `https://api.${URLBASE}.${DOMINIO}.com.ar`;
```
</CodeGroup>

<Tip>
  Mantené separadas las credenciales de cada ambiente y nunca las incluyas en el repositorio de código. Usá variables de entorno o un gestor de secretos.
</Tip>
