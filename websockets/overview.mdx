La **API WebSocket** permite operar de forma **asíncrona**: ingresar y cancelar órdenes, suscribirse a Execution Reports y recibir Market Data en tiempo real, **sin necesidad de hacer polling**.

Funcionalidades disponibles:

- **Órdenes:** ingresar, cancelar y suscribirse a Execution Reports (de una cuenta, de varias o de todas).
- **Market Data:** suscripción en tiempo real.

## URL de conexión

| Ambiente | URL |
| --- | --- |
| Producción | `wss://api.{urlbase}.(matrizoms\|xoms).com.ar/` |
| Demo general | `wss://api.demo.matrizoms.com.ar/` |

- **`{urlbase}`** es la instancia de tu ALyC.
- **`matrizoms` o `xoms`**: usá el dominio que te fue asignado. Ver [Ambientes](/environments).

<Note>
  El WebSocket usa el **mismo host** que la API REST de Trading, con el esquema `wss://`. El token se obtiene por REST contra ese mismo host.
</Note>

## Cómo conectarte

<Steps>
  <Step title="Obtené el token por REST">
    Pedí el token con `POST /auth/getToken` contra la URL base `https://` de tu ambiente. El token llega en el header de respuesta `X-Auth-Token` y es válido por 24 horas. Ver [Autenticación](/authentication).
  </Step>
  <Step title="Abrí la conexión enviando el token">
    Enviá `X-Auth-Token` como **header HTTP del handshake** o como **query parameter** de la URL (ver la sección siguiente).
  </Step>
  <Step title="Suscribite antes de operar">
    Enviá las suscripciones que necesites: [Execution Reports](/websockets/orders/subscribe-execution-reports) (`os`) para conocer el resultado de tus órdenes y [Market Data](/websockets/market-data/subscribe) (`smd`) para recibir precios.
  </Step>
  <Step title="Operá y procesá los mensajes entrantes">
    Enviá órdenes (`no`) y cancelaciones (`co`), y procesá los mensajes que llegan del servidor: `or` (Execution Report) y `Md` (Market Data).
  </Step>
</Steps>

## Autenticación de la conexión

La API acepta el token por cualquiera de estas dos vías:

<Tabs>
  <Tab title="Header en el handshake (recomendado)">
    Enviá el header HTTP `X-Auth-Token` en el request de apertura (handshake) del WebSocket:

    ```http
    GET / HTTP/1.1
    Host: api.demo.matrizoms.com.ar
    Upgrade: websocket
    Connection: Upgrade
    X-Auth-Token: <token>
    ```

    Es la opción **recomendada para backends** (Python, Node.js, C#, Java), porque el token no queda expuesto en la URL.
  </Tab>
  <Tab title="Query parameter en la URL">
    Agregá el token como parámetro `X-Auth-Token` en la URL de conexión:

    ```text
    wss://api.{urlbase}.(matrizoms|xoms).com.ar/?X-Auth-Token=<token>
    ```

    Es útil en **navegadores y frontends**, donde el cliente WebSocket nativo no permite enviar headers personalizados. Codificá siempre el token con `encodeURIComponent` (o equivalente).
  </Tab>
</Tabs>

<Warning>
  Con el método de **query parameter**, el token queda incluido en la URL y puede registrarse en logs de proxies, servidores o en el historial de herramientas de depuración. Usalo solo cuando no puedas enviar headers. Además, en un frontend **no expongas usuario y contraseña**: obtené el token desde tu backend y entregáselo al navegador.
</Warning>

## Ejemplos de conexión

Cada ejemplo abre la conexión, se suscribe a los Execution Reports de la cuenta `"30"` y a Market Data de `DLR/DIC26`, e imprime los mensajes recibidos.

<CodeGroup>
```python Python (header)
# pip install requests "websockets>=14"
import asyncio
import json
import os

import requests
import websockets

URLBASE = os.environ["MATRIZ_URLBASE"]                    # ej.: "demo"
DOMINIO = os.environ.get("MATRIZ_DOMINIO", "matrizoms")   # "matrizoms" o "xoms"
REST_URL = f"https://api.{URLBASE}.{DOMINIO}.com.ar"
WS_URL = f"wss://api.{URLBASE}.{DOMINIO}.com.ar/"


def obtener_token() -> str:
    respuesta = requests.post(
        f"{REST_URL}/auth/getToken",
        headers={
            "X-Username": os.environ["MATRIZ_USERNAME"],
            "X-Password": os.environ["MATRIZ_PASSWORD"],
        },
        timeout=10,
    )
    respuesta.raise_for_status()
    return respuesta.headers["X-Auth-Token"]


async def main() -> None:
    token = obtener_token()
    async with websockets.connect(
        WS_URL,
        additional_headers={"X-Auth-Token": token},
    ) as ws:
        # Execution Reports de la cuenta "30" (la cuenta va como texto)
        await ws.send(json.dumps({"type": "os", "account": {"id": "30"}}))

        # Market Data de DLR/DIC26: puntas y último precio
        await ws.send(json.dumps({
            "type": "smd",
            "level": 1,
            "entries": ["BI", "OF", "LA"],
            "products": [{"symbol": "DLR/DIC26", "marketId": "ROFX"}],
            "depth": 1,
        }))

        async for crudo in ws:
            mensaje = json.loads(crudo)
            if mensaje.get("type") == "or":
                reporte = mensaje["orderReport"]
                print("Execution Report:", reporte["clOrdId"], reporte["status"])
            elif mensaje.get("type") == "Md":
                print("Market Data:", mensaje["instrumentId"]["symbol"], mensaje["marketData"])
            else:
                print("Otro mensaje:", mensaje)


asyncio.run(main())
```

```javascript Node.js (header)
// npm install ws   ·   Node.js 18 o superior (ES modules)
import WebSocket from "ws";

const URLBASE = process.env.MATRIZ_URLBASE;                 // ej.: "demo"
const DOMINIO = process.env.MATRIZ_DOMINIO ?? "matrizoms";  // "matrizoms" o "xoms"
const REST_URL = `https://api.${URLBASE}.${DOMINIO}.com.ar`;
const WS_URL = `wss://api.${URLBASE}.${DOMINIO}.com.ar/`;

async function obtenerToken() {
  const respuesta = await fetch(`${REST_URL}/auth/getToken`, {
    method: "POST",
    headers: {
      "X-Username": process.env.MATRIZ_USERNAME,
      "X-Password": process.env.MATRIZ_PASSWORD,
    },
  });
  if (!respuesta.ok) {
    throw new Error(`No se pudo obtener el token: HTTP ${respuesta.status}`);
  }
  return respuesta.headers.get("X-Auth-Token");
}

const token = await obtenerToken();
const ws = new WebSocket(WS_URL, { headers: { "X-Auth-Token": token } });

ws.on("open", () => {
  // Execution Reports de la cuenta "30" (la cuenta va como texto)
  ws.send(JSON.stringify({ type: "os", account: { id: "30" } }));

  // Market Data de DLR/DIC26: puntas y último precio
  ws.send(JSON.stringify({
    type: "smd",
    level: 1,
    entries: ["BI", "OF", "LA"],
    products: [{ symbol: "DLR/DIC26", marketId: "ROFX" }],
    depth: 1,
  }));
});

ws.on("message", (datos) => {
  const mensaje = JSON.parse(datos.toString());
  if (mensaje.type === "or") {
    const reporte = mensaje.orderReport;
    console.log("Execution Report:", reporte.clOrdId, reporte.status);
  } else if (mensaje.type === "Md") {
    console.log("Market Data:", mensaje.instrumentId.symbol, mensaje.marketData);
  } else {
    console.log("Otro mensaje:", mensaje);
  }
});

ws.on("close", (codigo, motivo) => {
  console.log("Conexión cerrada:", codigo, motivo.toString());
});

ws.on("error", (error) => {
  console.error("Error de WebSocket:", error.message);
});
```

```javascript Navegador (query parameter)

  const mensaje = JSON.parse(evento.data);
  if (mensaje.type === "Md") {

});
```

## Tipos de mensaje

Todos los mensajes son objetos JSON con un campo `type` que indica su tipo.

| `type` | Dirección | Descripción |
| --- | --- | --- |
| `no` | Cliente → servidor | [Ingresar una orden](/websockets/orders/new-order). |
| `co` | Cliente → servidor | [Cancelar una orden](/websockets/orders/cancel-order). |
| `os` | Cliente → servidor | [Suscribirse a Execution Reports](/websockets/orders/subscribe-execution-reports). |
| `smd` | Cliente → servidor | [Suscribirse a Market Data](/websockets/market-data/subscribe). |
| `or` | Servidor → cliente | [Execution Report](/websockets/orders/execution-report-message): estado actualizado de una orden. |
| `Md` | Servidor → cliente | [Mensaje de Market Data](/websockets/market-data/market-data-message). |

<Info>
  Respetá mayúsculas y minúsculas del campo `type`: los mensajes de Market Data llegan como `"Md"` (con M mayúscula).
</Info>

## Ciclo de vida de la conexión

<Steps>
  <Step title="Apertura">
    Obtené un token vigente y abrí la conexión con `X-Auth-Token`.
  </Step>
  <Step title="Suscripción">
    Enviá tus suscripciones (`os`, `smd`) inmediatamente después de abrir la conexión y **antes** de enviar órdenes: sin la suscripción a Execution Reports no vas a recibir el resultado de tus órdenes.
  </Step>
  <Step title="Operación">
    Enviá órdenes y cancelaciones, y procesá los mensajes `or` y `Md` a medida que llegan.
  </Step>
  <Step title="Cierre">
    Cerrá la conexión en forma ordenada cuando tu aplicación termine. Si la conexión se cierra de forma inesperada, aplicá la estrategia de reconexión.
  </Step>
</Steps>

## Reconexión

Diseñá tu cliente asumiendo que la conexión puede cortarse en cualquier momento (cortes de red, mantenimiento, vencimiento del token). Recomendaciones:

- **Reintentá con espera exponencial** (por ejemplo, 1, 2, 4, 8… segundos, con un tope) para no saturar el servidor.
- **Renová el token antes de reconectar** si está cerca de cumplir sus 24 horas de validez.
- **Tratá cada conexión nueva como vacía:** volvé a enviar todas tus suscripciones (`os` y `smd`).
- **Reconciliá el estado de tus órdenes:** los Execution Reports emitidos mientras estabas desconectado pueden haberse perdido. Después de reconectar, consultá [Órdenes activas por cuenta](/order-routing/status/actives-by-account) por REST o suscribite con `snapshotOnlyActive`.
- **No reenvíes órdenes automáticamente** tras un corte: primero verificá si la orden original llegó al mercado, para no duplicarla.

<Accordion title="Ejemplo en Python: reconexión con espera exponencial" icon="rotate">
```python
# pip install requests "websockets>=14"
import asyncio
import json
import os
import time

import requests
import websockets

URLBASE = os.environ["MATRIZ_URLBASE"]
DOMINIO = os.environ.get("MATRIZ_DOMINIO", "matrizoms")
REST_URL = f"https://api.{URLBASE}.{DOMINIO}.com.ar"
WS_URL = f"wss://api.{URLBASE}.{DOMINIO}.com.ar/"

VIGENCIA_TOKEN = 24 * 60 * 60
MARGEN_TOKEN = 60 * 60  # renueva una hora antes del vencimiento

SUSCRIPCIONES = [
    {"type": "os", "account": {"id": "30"}, "snapshotOnlyActive": True},
    {
        "type": "smd",
        "level": 1,
        "entries": ["BI", "OF", "LA"],
        "products": [{"symbol": "DLR/DIC26", "marketId": "ROFX"}],
        "depth": 1,
    },
]

_token = None
_emitido_en = 0.0


def token_vigente() -> str:
    global _token, _emitido_en
    if _token is None or time.time() - _emitido_en > VIGENCIA_TOKEN - MARGEN_TOKEN:
        respuesta = requests.post(
            f"{REST_URL}/auth/getToken",
            headers={
                "X-Username": os.environ["MATRIZ_USERNAME"],
                "X-Password": os.environ["MATRIZ_PASSWORD"],
            },
            timeout=10,
        )
        respuesta.raise_for_status()
        _token = respuesta.headers["X-Auth-Token"]
        _emitido_en = time.time()
    return _token


def procesar(mensaje: dict) -> None:
    print(mensaje.get("type"), mensaje)


async def ejecutar() -> None:
    espera = 1
    while True:
        try:
            async with websockets.connect(
                WS_URL,
                additional_headers={"X-Auth-Token": token_vigente()},
            ) as ws:
                espera = 1  # conexión exitosa: reinicia la espera
                for suscripcion in SUSCRIPCIONES:
                    await ws.send(json.dumps(suscripcion))
                async for crudo in ws:
                    procesar(json.loads(crudo))
        except (websockets.ConnectionClosed, OSError) as error:
            print(f"Conexión perdida ({error}). Reintentando en {espera} s…")
        await asyncio.sleep(espera)
        espera = min(espera * 2, 60)


asyncio.run(ejecutar())
```
