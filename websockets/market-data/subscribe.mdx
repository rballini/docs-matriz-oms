Con el mensaje **`smd`** (subscribe market data) te suscribís para recibir **Market Data en tiempo real** de los instrumentos indicados, sin necesidad de hacer un request cada vez que la necesitás.

El servidor envía un mensaje [`Md`](/websockets/market-data/market-data-message) **por cada instrumento suscripto, cada vez que cambia** su Market Data, e incluye solo los datos pedidos en `entries`.

## Campos del mensaje

<ParamField body="type" type="string" required>
  Tipo de mensaje. Valor fijo: `"smd"`.
</ParamField>

<ParamField body="level" type="integer">
  Nivel de la suscripción. En los ejemplos se envía `1`.
</ParamField>

<ParamField body="entries" type="string[]" required>
  Lista de entries de Market Data que el servidor va a devolver. Ej.: `["BI", "OF", "LA"]`. Ver la tabla de entries más abajo.
</ParamField>

<ParamField body="products" type="object[]" required>
  Instrumentos a los que te querés suscribir.
  <Expandable title="propiedades de cada producto">
    <ParamField body="symbol" type="string" required>
      Símbolo del instrumento. Ej.: `"DLR/DIC26"`.
    </ParamField>
    <ParamField body="marketId" type="string" required>
      ID del mercado. Valor permitido: `"ROFX"`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="depth" type="integer" default="1">
  Opcional. Profundidad del book, de `1` a `5`. Por defecto se devuelve el **top of book** (profundidad `1`).
</ParamField>

## Entries disponibles

| Entry | Significado | Descripción |
| --- | --- | --- |
| `BI` | Bids | Mejor oferta de compra. |
| `OF` | Offers | Mejor oferta de venta. |
| `LA` | Last | Último precio operado. |
| `OP` | Opening Price | Precio de apertura. |
| `CL` | Closing Price | Precio de cierre de la rueda anterior. |
| `SE` | Settlement Price | Precio de ajuste (solo futuros). |
| `HI` / `LO` | High / Low | Precio máximo / mínimo de la rueda. |
| `TV` | Trade Volume | Volumen operado (contratos/nominales). |
| `OI` | Open Interest | Interés abierto (solo futuros). |
| `IV` | Index Value | Valor del índice (solo índices). |
| `EV` / `NV` | Effective / Nominal Volume | Volumen efectivo / nominal (solo instrumentos de BYMA). |
| `ACP` | Auction Price | Precio de cierre del día corriente. |

Más detalle en [Market Data Entries](/reference/market-data-entries).

## Ejemplos de código

<CodeGroup>
```python Python
# pip install "websockets>=14"
import asyncio
import json
import os

import websockets

WS_URL = f"wss://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar/"
TOKEN = os.environ["MATRIZ_TOKEN"]  # obtenido con POST /auth/getToken


async def main() -> None:
    async with websockets.connect(WS_URL, additional_headers={"X-Auth-Token": TOKEN}) as ws:
        await ws.send(json.dumps({"type": "smd", "level": 1, "entries": ["BI", "OF", "LA"], "products": [{"symbol": "DLR/DIC26", "marketId": "ROFX"}, {"symbol": "DLR/ENE27", "marketId": "ROFX"}], "depth": 2}))

        async for crudo in ws:
            mensaje = json.loads(crudo)
            if mensaje.get("type") != "Md":
                continue
            simbolo = mensaje["instrumentId"]["symbol"]
            md = mensaje["marketData"]
            compra = md.get("BI") or []
            venta = md.get("OF") or []
            print(simbolo,
                  "compra:", compra[0] if compra else None,
                  "venta:", venta[0] if venta else None,
                  "último:", md.get("LA"))


asyncio.run(main())
```

```javascript Node.js
// npm install ws   ·   Node.js 18 o superior (ES modules)
import WebSocket from "ws";

const WS_URL = `wss://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar/`;
const ws = new WebSocket(WS_URL, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN }, // obtenido con POST /auth/getToken
});

ws.on("open", () => {
  ws.send(JSON.stringify({"type": "smd", "level": 1, "entries": ["BI", "OF", "LA"], "products": [{"symbol": "DLR/DIC26", "marketId": "ROFX"}, {"symbol": "DLR/ENE27", "marketId": "ROFX"}], "depth": 2}));
});

ws.on("message", (datos) => {
  const mensaje = JSON.parse(datos.toString());
  if (mensaje.type !== "Md") return;
  const simbolo = mensaje.instrumentId.symbol;
  const md = mensaje.marketData;
  console.log(simbolo, "compra:", md.BI?.[0], "venta:", md.OF?.[0], "último:", md.LA);
});

ws.on("error", (error) => console.error("Error de WebSocket:", error.message));
```
</CodeGroup>
