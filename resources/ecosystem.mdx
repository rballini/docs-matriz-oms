## Librerías de terceros usadas en esta documentación

Los ejemplos de este portal usan librerías estándar y de uso extendido. No son mantenidas por Matriz OMS:

| Lenguaje | Uso | Librería | Instalación |
| --- | --- | --- | --- |
| Python | REST | `requests` | `pip install requests` |
| Python | WebSocket | `websockets` (versión 14 o superior) | `pip install "websockets>=14"` |
| Node.js | REST | `fetch` nativo (Node.js 18 o superior) | — |
| Node.js | WebSocket | `ws` | `npm install ws` |
| Navegador | WebSocket | `WebSocket` nativo | — |
