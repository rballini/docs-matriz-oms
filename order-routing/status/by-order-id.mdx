Según la documentación anterior, este método devuelve el **estado de una orden consultando por su Order ID**.

```http
GET https://api.{urlbase}.(matrizoms|xoms).com.ar/rest/order/byOrderId
```

## Origen y relación con `actives`

El manual vigente de Matriz OMS **no incluye este endpoint**: define [Órdenes activas por cuenta](/order-routing/status/actives-by-account) (`/rest/order/actives`) como la consulta principal por cuenta.

La documentación anterior presenta esta consulta con dos inconsistencias:

- Aunque el método se llama "por Order ID", el único parámetro que documenta es **`accountId`**, no un Order ID.
- La URL de ejemplo que acompaña la sección no apunta a `/rest/order/byOrderId`, sino a **`/rest/order/actives?accountId=10`**. La respuesta de ejemplo corresponde, por lo tanto, a la consulta de órdenes activas.

<Tip>
  Mientras este endpoint no se valide, **usá las consultas vigentes**: [Órdenes activas por cuenta](/order-routing/status/actives-by-account) para las órdenes vivas de una cuenta, [Último estado por Client Order ID](/order-routing/status/last-by-client-order-id) para un request puntual o [Estado de orden por Execution ID](/order-routing/status/by-execution-id) para una ejecución.
</Tip>

## Parámetros

Parámetro según figura en la documentación anterior:

<ParamField query="accountId" type="integer" required>
  Número de cuenta, como **entero** (REST). Ej.: `30`. La documentación anterior no incluye un parámetro para el Order ID.
</ParamField>

## Ejemplos de request

Request armado tal como lo describe la documentación anterior:

<CodeGroup>
```bash cURL
# BASE_URL=https://api.{urlbase}.matrizoms.com.ar  (o .xoms.com.ar según tu ambiente)
curl --get "$BASE_URL/rest/order/byOrderId" \
  -H "X-Auth-Token: $MATRIZ_TOKEN" \
  --data-urlencode "accountId=30"
```

```python Python
import os
import requests

BASE_URL = f"https://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar"
TOKEN = os.environ["MATRIZ_TOKEN"]

respuesta = requests.get(
    f"{BASE_URL}/rest/order/byOrderId",
    headers={"X-Auth-Token": TOKEN},
    params={"accountId": 30},
    timeout=10,
)
respuesta.raise_for_status()
datos = respuesta.json()

if datos["status"] == "OK":
    for orden in datos["orders"]:
        print(orden["clOrdId"], orden["status"], orden["cumQty"], "/", orden["orderQty"])
else:
    print("Error:", datos.get("description") or datos.get("message"))
```

```javascript Node.js
// Node.js 18 o superior (fetch nativo)
const BASE_URL = `https://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar`;

const params = new URLSearchParams({ accountId: "30" });

const respuesta = await fetch(`${BASE_URL}/rest/order/byOrderId?${params}`, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN },
});
const datos = await respuesta.json();

if (datos.status === "OK") {
  for (const orden of datos.orders) {
    console.log(orden.clOrdId, orden.status, `${orden.cumQty}/${orden.orderQty}`);
  }
} else {
  console.error("Error:", datos.description ?? datos.message);
}
```
</CodeGroup>
