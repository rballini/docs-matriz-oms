Devuelve el **último estado de todos los requests** (Client Order IDs) asociados a una cuenta.

```http
GET https://api.{urlbase}.(matrizoms|xoms).com.ar/rest/order/all
```

<Note>
  La respuesta tiene **un elemento por request**, no por orden. Si se dio de alta una orden y después se la canceló, la consulta devuelve **dos elementos**: el último estado del request de alta y el último estado del request de cancelación. Ambos comparten el mismo `orderId`. Ver [Client Order ID vs. Order ID](/guides/client-order-id-vs-order-id).
</Note>

## Parámetros

<AuthHeader />

<ParamField query="accountId" type="integer" required>
  Número de cuenta. En la API REST es un **entero**. Ej.: `30`.
</ParamField>

<Note>
  En la API REST la cuenta se envía como **entero** (`accountId=30`), pero en la respuesta llega como **texto** dentro de `accountId.id` (`"id": "30"`). En la API WebSocket la cuenta siempre se envía como texto. Ver la aclaración completa en [Ingresar una orden](/order-routing/new-order).
</Note>

## Ejemplos de request

<CodeGroup>
```bash cURL
# BASE_URL=https://api.{urlbase}.matrizoms.com.ar  (o .xoms.com.ar según tu ambiente)
curl --get "$BASE_URL/rest/order/all" \
  -H "X-Auth-Token: $MATRIZ_TOKEN" \
  --data-urlencode "accountId=30"
```

```python Python
import os
import requests

BASE_URL = f"https://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar"
TOKEN = os.environ["MATRIZ_TOKEN"]

respuesta = requests.get(
    f"{BASE_URL}/rest/order/all",
    headers={"X-Auth-Token": TOKEN},
    params={"accountId": 30},
    timeout=10,
)
respuesta.raise_for_status()
datos = respuesta.json()

if datos["status"] == "OK":
    # Agrupa los requests por orden (orderId)
    por_orden = {}
    for request in datos["orders"]:
        por_orden.setdefault(request["orderId"], []).append(request)
    for order_id, requests_orden in por_orden.items():
        print(order_id, [(r["clOrdId"], r["status"]) for r in requests_orden])
else:
    print("Error:", datos.get("description") or datos.get("message"))
```

```javascript Node.js
// Node.js 18 o superior (fetch nativo)
const BASE_URL = `https://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar`;

const params = new URLSearchParams({ accountId: "30" });

const respuesta = await fetch(`${BASE_URL}/rest/order/all?${params}`, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN },
});
const datos = await respuesta.json();

if (datos.status === "OK") {
  // Agrupa los requests por orden (orderId)
  const porOrden = new Map();
  for (const request of datos.orders) {
    const lista = porOrden.get(request.orderId) ?? [];
    lista.push(request);
    porOrden.set(request.orderId, lista);
  }
  for (const [orderId, lista] of porOrden) {
    console.log(orderId, lista.map((r) => [r.clOrdId, r.status]));
  }
} else {
  console.error("Error:", datos.description ?? datos.message);
}
```
</CodeGroup>

## Respuesta

<Note>
  El contenido de la respuesta es de referencia y podría sufrir modificaciones. Los valores de los ejemplos son ilustrativos.
</Note>

<ResponseField name="status" type="string">
  Resultado del request: `OK` si fue exitoso o `ERROR` si falló. Este `status` es el del request, no el de la orden: el estado de cada orden viene en su propio campo `status`. Ver [Errores](/reference/errors).
</ResponseField>

<ResponseField name="orders" type="object[]">
  Lista con el último estado de cada request de la cuenta.
