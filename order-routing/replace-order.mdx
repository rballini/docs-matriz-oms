Permite **reemplazar una orden** ingresada en el mercado, modificando su **precio** y su **tamaño**. La orden se identifica por el Client Order ID (`clOrdId`) del request original de alta.

```http
GET https://api.{urlbase}.(matrizoms|xoms).com.ar/rest/order/replaceById
```

## Parámetros

<AuthHeader />

<ParamField query="clOrdId" type="string" required>
  ID del request original, devuelto en `order.clientId` al [ingresar la orden](/order-routing/new-order). Ej.: `user1179491234567890`.
</ParamField>

<ParamField query="proprietary" type="string" required>
  ID del participante de mercado (fijo por cuenta). Usá el valor devuelto en `order.proprietary` al ingresar la orden. Ej.: `PBCP`.
</ParamField>

<ParamField query="orderQty" type="integer" required>
  Nuevo tamaño de la orden.
</ParamField>

<ParamField query="price" type="number" required>
  Nuevo precio de la orden. Ej.: `1597.5`.
</ParamField>

## Ejemplos de request

Reemplazo de la orden `user1179491234567890`: nuevo precio `1597.5` y nuevo tamaño `15`.

<CodeGroup>
```bash cURL
# BASE_URL=https://api.{urlbase}.matrizoms.com.ar  (o .xoms.com.ar según tu ambiente)
curl --get "$BASE_URL/rest/order/replaceById" \
  -H "X-Auth-Token: $MATRIZ_TOKEN" \
  --data-urlencode "clOrdId=user1179491234567890" \
  --data-urlencode "proprietary=PBCP" \
  --data-urlencode "orderQty=15" \
  --data-urlencode "price=1597.5"
```

```python Python
import os
import requests

BASE_URL = f"https://api.{os.environ['MATRIZ_URLBASE']}.{os.environ.get('MATRIZ_DOMINIO', 'matrizoms')}.com.ar"
TOKEN = os.environ["MATRIZ_TOKEN"]

respuesta = requests.get(
    f"{BASE_URL}/rest/order/replaceById",
    headers={"X-Auth-Token": TOKEN},
    params={
        "clOrdId": "user1179491234567890",
        "proprietary": "PBCP",
        "orderQty": 15,
        "price": 1597.5,
    },
    timeout=10,
)
respuesta.raise_for_status()
datos = respuesta.json()

if datos["status"] == "OK":
    print("Reemplazo recibido. clOrdId:", datos["order"]["clientId"])
else:
    print("Error:", datos.get("description") or datos.get("message"))
```

```javascript Node.js
// Node.js 18 o superior (fetch nativo)
const BASE_URL = `https://api.${process.env.MATRIZ_URLBASE}.${process.env.MATRIZ_DOMINIO ?? "matrizoms"}.com.ar`;

const params = new URLSearchParams({
  clOrdId: "user1179491234567890",
  proprietary: "PBCP",
  orderQty: "15",
  price: "1597.5",
});

const respuesta = await fetch(`${BASE_URL}/rest/order/replaceById?${params}`, {
  headers: { "X-Auth-Token": process.env.MATRIZ_TOKEN },
});
const datos = await respuesta.json();

if (datos.status === "OK") {
  console.log("Reemplazo recibido. clOrdId:", datos.order.clientId);
} else {
  console.error("Error:", datos.description ?? datos.message);
}
```
